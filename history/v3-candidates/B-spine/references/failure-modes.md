# Failure modes

Read this file at Step 5, before you deliver. Read it also when a run feels stuck, slow or timid. Each entry gives the sign, the cause and the fix. Several come from real test runs.

## The timid job

- **Sign:** a normal job with a long report on top. The plan fits in one ordinary pass.
- **Cause:** restraint clauses used as an excuse. In early tests, every agent started small this way.
- **Fix:** run the stretch in Step 2. If the user typed the slash command, use restraint only for trivial tasks.

## Quota thinking

- **Sign:** the count is hit with near-clones.
- **Cause:** a number in the skill read as a target.
- **Fix:** numbers are examples. Merge briefs that differ only in surface. Fewer real options beat many copies.

## Mode collapse

- **Sign:** variants converge on one idea.
- **Cause:** one context wrote them all, each built on the last.
- **Fix:** write all briefs first. Use one subagent per brief. Without subagents, build each in its own pass and say that one author made them.

## The oversized first run

- **Sign:** a grid runs past ten minutes before you learn it was too big.
- **Fix:** time one cell first. Size the grid to finish in a few minutes. Say what a larger grid would add.

## Proof theatre

- **Sign:** a screenshot that does not show the claim, or a "pass" with no artefact.
- **Fix:** link each claim to evidence that shows it, and give a recheck command.

## A check that cannot fail

- **Sign:** a check passes on everything, including the broken original. In a test run, a contrast check could not fail.
- **Fix:** run each check once on a known-bad input before you trust it.

## Ceremony and preamble bloat

- **Sign:** an eight-line contract and a six-part report for a small result.
- **Fix:** fit the length to the job. A small job needs three contract lines and one line per report item.

## Waiting for a reply that cannot come

- **Sign:** "tell me which parts to combine" in a one-shot run.
- **Fix:** merge the best parts yourself. Say which part came from which variant. Put open questions in "Needs you".

## Self-judged taste

- **Sign:** you pick your own favourite with no criterion.
- **Fix:** write the criterion first. Use a fresh pass with no context if you can. Otherwise label it "self-review". Add objective checks.

## Anchoring on examples

- **Sign:** you copy an example's count or tool list as a checklist.
- **Fix:** examples show shape, not size. Choose tools that fit the cause.

## Endless loops

- **Sign:** passes continue with no measurable gain.
- **Fix:** stop after two passes in a row with no gain. Report where you stopped.

## Unasked formats

- **Sign:** formats the destination does not need.
- **Fix:** find the destination first. Stop there.

## Over-polish of the wrong thing

- **Sign:** effort where the outcome does not depend on it.
- **Fix:** apply "Earned": if removing it changes nothing, cut it.

## The dump

- **Sign:** all the output, no winner, no proof, no map.
- **Fix:** name the winner and why, give proof in one minute, and link one place to browse the rest.
